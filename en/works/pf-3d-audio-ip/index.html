Mobile 3D-Audio Sound-Rendering IP

모바일 3D 오디오 사운드 렌더링 IP

2020–2022 · Core IP for system semiconductors
이 글의 상세 본문(구조·설계·기여)은 한국어로 제공됩니다 · Detailed sections below are in Korean

모바일 기기에 내장되어 실시간으로 3D 오디오(입체 음향)를 렌더링하는 시스템반도체 핵심 IP다. 이어폰·스피커를 통해 소리가 특정 방향·거리에서 들리는 것처럼 공간감 있는 음향을 재생하도록, 기기 안에서 오디오 신호를 실시간 처리한다.

IP 코어 자체뿐 아니라 이를 구동하는 리눅스 소프트웨어, 칩셋과 통신하는 API 프로토콜, 그리고 디바이스 드라이버까지 하드웨어-소프트웨어 스택 전반을 개발했다. 모바일이라는 제약(전력·연산 자원) 안에서 실시간 입체 음향을 구현하는 데 초점을 두었다.

Structure · Design

시스템반도체(SoC)에 통합되는 오디오 렌더링 IP를 중심으로, 상위의 애플리케이션이 칩셋의 오디오 렌더링 기능을 호출할 수 있도록 하는 API 프로토콜, 운영체제(리눅스)에서 IP를 구동하고 오디오 스트림을 처리하는 소프트웨어, 그리고 하드웨어 IP와 OS를 잇는 디바이스 드라이버로 구성된다. 입력 오디오를 3D 공간 음향으로 변환하는 신호처리를 IP 레벨에서 실시간으로 수행하고, 리눅스 SW·API·드라이버 계층이 이를 모바일 시스템에 통합하는 하드웨어-소프트웨어 협조 설계 구조다.

Design goals

모바일 기기에서 별도의 고성능 프로세서 없이도 실시간 3D 오디오를 재생할 수 있도록, 렌더링 연산을 전용 IP로 하드웨어화하는 것이 핵심 목표였다. 소프트웨어만으로 3D 오디오를 처리하면 연산 부하와 지연·전력 소모가 커지는데, 이를 시스템반도체의 핵심 IP로 내려 실시간성과 전력 효율을 확보하고자 했다. 동시에 리눅스 SW·API 프로토콜·드라이버를 함께 개발해, IP가 실제 모바일 기기에서 상위 애플리케이션과 매끄럽게 연동되도록 하는 통합성을 설계 목표로 삼았다.
