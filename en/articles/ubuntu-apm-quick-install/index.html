Ubuntu APM Quick Install (Apache, PHP, MySQL)

Only the essential commands for putting Apache, MySQL and PHP on Ubuntu, in order — plus what to do when the MySQL password prompt never appears and when PHP won't run.

DP
Daeseung Park AI & Software Systems Engineer · KAIST April 18, 2024 · 1 min read

Everything unnecessary for installing APM (Apache, PHP, MySQL) on Ubuntu has been left out — only the essential core commands remain.

1. Initial Ubuntu setup

sudo apt-get update

2. Install Apache

sudo apt-get install apache2

3. Allow it through the firewall

sudo ufw allow 'Apache'

4. Install MySQL

sudo apt install mysql-server

5. Set the MySQL password

sudo mysql_secure_installation

6. If the command above never asks you to set a password, run the commands below and then run step 5 again

sudo mysql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password by 'mynewpassword';

Install PHP

sudo apt install php libapache2-mod-php php-mysql

*If PHP doesn't work once the web server is running > edit the file below

vi /etc/apache2/mods-enabled/mime.conf

Add the line below in a suitable place, then restart Apache2

AddType application/x-httpd-php .html .htm .php
