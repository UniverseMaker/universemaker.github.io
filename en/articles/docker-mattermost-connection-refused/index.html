[Docker] Mattermost Unreachable from Outside: Connection Refused, Mattermost-preview

When a Dockerized mattermost-preview answers outside connections with Connection Refused, recreate the container with the --add-host option.

DP
Daeseung Park AI & Software Systems Engineer · KAIST May 23, 2024 · 1 min read

If the server can't be reached from outside, recreate the container with the command below and use that instead.

docker run --name mattermost-preview -d --publish 8065:8065 --add-host dockerhost:127.0.0.1 mattermost/mattermost-preview

The key part is --add-host dockerhost:127.0.0.1.

This is the step that allows outside access; without that option you may see a Connection Refused error.
