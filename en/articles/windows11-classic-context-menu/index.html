Making “Show more options” the Default Right-Click Menu in Windows 11

A registry command that makes Windows 11 open the full, classic right-click menu (“Show more options”) instead of the simplified one — and the command that puts it back.

DP
Daeseung Park AI & Software Systems Engineer · KAIST September 3, 2025 · 1 min read

Run CMD as administrator, then enter the commands below. (The Korean comments read: register the registry key / kill Explorer / start Explorer.)

# 레지스트리 등록
reg.exe add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve

# 익스플로러 종료
taskkill /f /im explorer.exe

# 익스플로러 실행
explorer

To restore the original behavior, enter the command below 🙂 (comment: remove the registry key)

# 레지스트리 제거
reg.exe delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f

If the commands don't work, check that you ran CMD as administrator!
