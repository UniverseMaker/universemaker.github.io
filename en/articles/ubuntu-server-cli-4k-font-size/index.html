Ubuntu Server CLI Mode on a 4K Monitor: A Dead-Simple Way to Enlarge the Font

When the Ubuntu Server console text on a 4K monitor is too small to read, one run of dpkg-reconfigure console-setup enlarges the font to Terminus 16x32.

DP
Daeseung Park AI & Software Systems Engineer · KAIST October 16, 2024 · 1 min read

Coming back to Linux (Ubuntu Server) after a while, I found the font on my 4K monitor so small that I couldn't read the text.

Let's enlarge the font in Linux CLI mode, the easy way.

Use the command below to enter the console font setup.

sudo dpkg-reconfigure console-setup

Go with the settings below, and press Next through the rest, leaving them at their defaults. (폰트 = font, 폰트크기 = font size.)

폰트: Terminus
폰트크기: 16x32

The font is now big enough to be reasonably readable! Done~!
