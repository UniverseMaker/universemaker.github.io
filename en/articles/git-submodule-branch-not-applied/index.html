(Git Error) Git Submodule Branch Won't Apply

When the branch set in .gitmodules is not applied to a submodule: force it with git config, verify it, then update with git submodule update --remote.

DP
Daeseung Park AI & Software Systems Engineer · KAIST August 20, 2025 · 1 min read

A Git submodule's branch can be set in the .gitmodules file shown below.

Sometimes, however, it doesn't take effect — in that case you can force it with the command below.

git config submodule.Captain/Libraries/submodule_name.branch Branchname

Replace submodule_name and Branchname with your own values.

git config --get submodule.Captain/Libraries/submodule_name.branch

After applying it, entering the command above should print the branch name you just forced. If nothing is printed, you need to edit the config file inside the .git folder directly.

git submodule update --remote

Once everything is applied, you can update the submodule with the command above. If it still doesn't take effect at this stage, delete everything inside the Libraries folder that holds the submodule.
