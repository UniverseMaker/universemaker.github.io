[WordPress] A Dead-Simple Fix for ERR_TOO_MANY_REDIRECTS After Enabling Cloudflare

I put Cloudflare in front of the blog to stop spam comments, and logging in started failing with ERR_TOO_MANY_REDIRECTS. The cause is an https↔http loop under the Flexible SSL mode — switching the encryption mode to Full fixes it.

DP
Daeseung Park AI & Software Systems Engineer · KAIST October 16, 2024 · 3 min read

Spam comments had recently increased enormously, so I put the site behind Cloudflare.

But then!!

Trying to log in, I got an ERR_TOO_MANY_REDIRECTS error...

A bit of searching turns up all kinds of fixes — edit Nginx, edit .htaccess, and so on...

Looking into the cause, it turns out the web service keeps handing requests back and forth between https and http and gets stuck in a loop.

It never used to do this — so why did it start after applying Cloudflare?

Going into the SSL settings menu on the Cloudflare dashboard, I found the default set to Flexible SSL.

Between the user and Cloudflare, traffic travels over SSL (https), but between Cloudflare and the origin server (my hosting server) it travels over http.

Just looking at it, this seems to be the problem... Let's change the setting. Click the Configure button on the right of the screen above.

Set it to Full and save.

Now every leg of the path talks https only. Did it fix things?

Ta-da!! It works ^^
