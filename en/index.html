AI · R&D

AddressKG — National Address Information Knowledge Graph

2026 · Neo4j · FastAPI · Python

A knowledge graph of Korean road-name addresses, built on Neo4j by decomposing the source data into nodes and links. It pairs a Core Network (HSM — hierarchical, spatial, and semantic relations) that follows the national standard ontology with an External Network (ESC) that links public datasets to address elements, and serves the result through ADDi, a hallucination-free address agent, alongside 3D visualisation and a full control API with a web console.

2026 · KAIST · Regional Innovation Cluster R&D — Urban Safety AI

Research software that reads video, sensor, geospatial, and text modalities on a single LLM backbone to recognise fire, flood, and collapse situations, and hands the result to partner systems through standard schemas.

Web · Services

ulogin — Universal Login and SSO Server That Keeps API Keys Out of Local Apps

2026 · GitHub · PHP 7.2+ / MySQL

JavaScript in a deployed page is not a secret. The moment you hand someone a local AI app with a hardcoded API key, the key ships with it — and once it leaks, someone else makes the calls while the bill stays yours. ulogin leaves the app as a single static HTML file, moves only the login to the server, and returns to each authenticated user exactly the secrets their tier allows.

About this Journal

This journal is a space for recording my research and thoughts. On topics I have worked on directly — large language models, time-series forecasting, conversational AI — I try to explain things as accurately and readably as possible. The goal is to capture how the research actually unfolded, including the judgments and trial-and-error, before it is compressed into a single line of a paper.

Every article is typeset to read like a book even in print. Feel free to save any piece you like as a PDF using your browser's print function.
