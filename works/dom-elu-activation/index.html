국내학술

ELU와 로지스틱 회귀의 비대칭 조합 함수를 활용한 순환신경망 성능 개선 연구

RNN Performance Improvement using Asymmetric Combination of ELU and Logistic Regression

한국산업정보학회 춘계학술대회 · 2022.10 · 주저자
저자 박대승 (주저자) 외 공저
요약 Summary지수 선형 단위(ELU)와 로지스틱·Tanh를 층마다 비대칭으로 조합한 활성함수로, 깊은 순환신경망의 고질병인 기울기 소실(Vanishing Gradient)을 완화한 연구다. '하나의 최적 활성함수'를 찾는 대신, 층마다 요구가 다르다면 층마다 다른 함수를 쓴다는 발상을 설계로 옮겼다.

역전파로 오차 신호가 앞쪽 층으로 전달될 때 활성함수의 기울기가 작으면 신호가 곱해질수록 0에 수렴해, 입력에 가까운 층은 사실상 학습이 멈춘다. 포화 구간에서 기울기가 거의 0이 되는 로지스틱·Tanh는 이 문제에 특히 취약하다.

본 연구는 양수 구간에서 기울기를 살리고 음수 구간에서 부드럽게 포화하며 출력 평균을 0 근처로 미는 ELU와, 로지스틱·Tanh를 층 위치에 따라 비대칭으로 조합했다. 각 함수의 장점이 다른 함수의 약점을 보완하도록 배치해, 앞단은 신호를 넓게 통과시키고 뒷단은 출력을 부드럽게 정돈하도록 역할을 나눴다.

여러 조합을 체계적으로 비교한 결과 비대칭 조합은 단일 활성함수 기준선 대비 평균 1.024%포인트 개선을 보였고, ELU-Tanh 조합이 정확도 0.9600으로 최고 성능을 냈다. 파라미터를 늘리지 않고 구성 요소의 배치만 바꿔 얻은, 추가 연산 비용이 거의 없는 이득이라는 점이 핵심이다.

왜 중요한가

아키텍처의 작은 변경(활성함수)만으로 평균 +1.024% 개선.

기여

ELU와 로지스틱·Tanh를 층별로 비대칭 조합하는 활성함수 설계로 기울기 소실을 완화해, 파라미터 증가 없이 평균 1.024%포인트 성능 개선을 달성했다.
