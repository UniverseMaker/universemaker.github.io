디지털 사이니지를 위한 머신러닝 기반 스마트 콘텐츠 관리 시스템 연구

A Study of Smart Contents Management System Using Machine Learning for Digital Signage

EEECS 2020 · 2020.12.21–22 · 주저자
저자 박대승 (주저자) 외 공저
요약 Summary머신러닝을 활용해 디지털 사이니지의 콘텐츠 편성을 자동으로 최적화하는 스마트 콘텐츠 관리 시스템을 연구한 논문이다. 어떤 콘텐츠가 언제·어디서 잘 작동했는지를 데이터로부터 학습해, 운영자가 일일이 편성하지 않아도 적합한 배치를 제안한다.

사이니지 콘텐츠 운영은 수많은 콘텐츠를 시간대·장소·맥락에 맞게 편성해야 하는 반복적이고 노동집약적인 일이다. 사람이 경험과 감으로 편성하는 방식은 규모가 커질수록 일관성과 효율을 유지하기 어렵다.

본 연구는 콘텐츠의 노출·반응 데이터를 학습해 어떤 맥락에서 어떤 콘텐츠가 잘 작동하는지를 모델이 정리하고, 이를 바탕으로 편성을 자동 최적화하는 관리 시스템을 설계했다. 사이니지가 단순한 '재생기'에서 '판단하는 화면'으로 바뀌는 지점이다.

콘텐츠 운영을 경험이 아니라 데이터 기반으로 자동화한 사례로, 맥락 인식 추천·이기종 사이니지와 함께 인터랙티브 사이니지 연구 계열의 운영 지능 축을 담당했다.

왜 중요한가

콘텐츠 운영을 데이터 기반으로 자동화.

기여

머신러닝 기반 콘텐츠 편성 최적화를 사이니지 운영에 적용해, 수작업 편성을 데이터 기반 자동 관리로 전환하는 스마트 콘텐츠 관리 체계를 제시했다.
