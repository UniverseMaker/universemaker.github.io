특허 등록

선택적 모델 적용 기능을 구비한 멀티 모델 헬스케어 챗봇 시스템

Multi-Model Healthcare Chatbot System with Selective Model Application

등록 10-2894533 (출원 10-2022-0130207) · 2025.12 등록 · 발명
저자 발명자: 김정길, 박대승 · 출원인: 남서울대학교 산학협력단
요약 Summary질의의 특성에 따라 서로 다른 처리 모델을 선택적으로 적용하는 멀티 모델 헬스케어 챗봇 시스템에 관한 것으로, 하나의 대화 흐름 안에서 질의 유형별로 가장 적합한 모델을 골라 응답 품질과 응답 속도의 균형을 도모한다.

단일 모델 기반 헬스케어 챗봇은 모든 질의를 동일한 방식으로 처리하기 때문에, 간단한 질의에는 과도한 연산을, 복잡·전문 질의에는 불충분한 정확도를 보이는 한계가 있다. 본 발명은 이러한 획일적 처리의 문제를 배경으로 한다.

제안 시스템은 입력된 질의의 성격(예: 단순 안내형인지, 전문 판단이 필요한 유형인지 등)을 먼저 파악하고, 미리 준비된 복수의 모델 중에서 해당 질의에 적합한 모델을 선택하여 응답을 생성한다.

이를 통해 가벼운 질의는 빠르게, 정확도가 중요한 질의는 그에 맞는 모델로 처리함으로써, 전체 대화 경험에서 정확도와 응답성 사이의 균형을 맞춘다.

구조 · 설계

청구의 핵심은 질의 특성을 분석하는 판별부와, 서로 다른 특성을 갖는 복수의 응답 모델, 그리고 판별 결과에 따라 적용할 모델을 선택하는 모델 선택부로 구성된 점에 있다. 모델들이 교체·추가 가능한 형태로 결합되어, 새로운 목적의 모델을 손쉽게 편입할 수 있는 선택 적용형 구조를 이룬다.

설계 목표

질의 유형에 관계없이 동일 모델을 쓰는 데서 오는 비효율(정확도 부족 또는 자원 과다)을 없애고, 각 질의에 가장 적합한 모델을 골라 적용함으로써 헬스케어 상담의 정확도와 응답 속도를 함께 최적화하는 것을 목적으로 한다.

왜 중요한가

정확도와 응답성의 균형을 모델 선택으로 최적화.

기여

계층적 다중 챗봇 특허와 함께 대화형 헬스케어 AI의 모델 운용 전략을 다각화한 출원으로, 상황에 맞는 모델 선택이라는 설계 원칙을 지식재산으로 구체화한다.
