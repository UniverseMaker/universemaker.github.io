Seq2Seq 해수 수온 예측 모델

2023 · ICTC 2023 · GitHub · Python/TensorFlow

다변량 입력을 사용하는 Seq2Seq(인코더–디코더) 시계열 모델로 해수 수온을 예측한다. ICTC 2023 발표 논문의 Python·TensorFlow 구현.

같은 연구에서 입력 변수를 고르기 위해 만든 다변량 상관분석 코드를 별도 저장소로 함께 공개했다. 부이 관측 변수(풍속·풍향·기압·습도·기온·파고·파주기·파향 등)를 정규화한 뒤 수온을 기준으로 상관계수 행렬을 뽑아 히트맵으로 그리고, 랜덤포레스트 회귀·분류로 변수 중요도를 산출해 어떤 변수를 Seq2Seq 입력에 넣을지 판단하는 데 썼다. 예측 모델의 핵심 코드는 담지 않은 분석 전용 스크립트다.
