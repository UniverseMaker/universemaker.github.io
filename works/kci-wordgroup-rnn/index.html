단어 그룹 확장 기법을 활용한 순환신경망(RNN) 알고리즘 성능 개선 연구

Performance Improvement of RNN Algorithm using Word Group Expansion Technique

산업융합연구 / 대한산업경영학회 · 2022.04 · 주저자
저자 박대승(Dae Seung Park, 주저자), 성열우(Yeol Woo Sung), 김청길(Cheong Ghil Kim)
초록 Abstract최근 인공지능(AI)과 딥러닝 발전으로 대화형 인공지능 챗봇의 중요성이 부각되고 있으며 다양한 분야에서 연구가 진행되고 있다. 챗봇을 만들기 위해서 직접 개발해 사용하기도 하지만 개발의 용이성을 위해 오픈소스 플랫폼이나 상업용 플랫폼을 활용하여 개발한다. 이러한 챗봇 플랫폼은 주로 RNN (Recurrent Neural Network)과 응용 알고리즘을 사용하며, 빠른 학습속도와 모니터링 및 검증의 용이성 그리고 좋은 추론 성능의 장점을 가지고 있다. 본 논문에서는 RNN과 응용 알고리즘의 추론 성능 향상방법을 연구하였다. 제안 방법은 RNN과 응용 알고리즘 적용 시 각 문장에 대한 핵심단어의 단어그룹에 대해 확장학습을 통해 데이터에 내재된 의미를 넓히는 기법을 사용하였다. 본 연구의 결과는 순환 구조를 갖는 RNN, GRU (Gated Recurrent Unit), LSTM (Long-short Term Memory) 세 알고리즘에서 최소 0.37%에서 최대 1.25% 추론 성능향상을 달성하였다. 본 연구를 통해 얻은 연구결과는 관련 산업에서 인공지능 챗봇 도입을 가속하고 다양한 RNN 응용 알고리즘을 활용하도록 하는데 기여할 수 있다. 향후 연구에서는 다양한 활성 함수들이 인공신경망 알고리즘의 성능 향상에 미치는 영향에 관한 연구가 필요할 것이다.

자연어 처리에서 데이터 증강은 단어 하나만 바꿔도 뜻이 어긋나기 쉬운 미묘한 문제를 안고 있다. 특히 한국어에서 무작위 치환·삭제 같은 거친 증강은 의미를 훼손하기 쉬워, 의미 구조를 존중하는 증강이 필요했다.

본 연구는 표준국어대사전에 등재된 유의어 관계를 근거로, 개별 단어를 하나씩 바꾸는 대신 유의어 묶음(단어그룹)을 오가며 표현 변이를 생성하는 확장학습 기법을 제안한다. 원문의 의미는 유지한 채 같은 개념의 여러 표면형을 모델이 학습하게 하는 것이 핵심이며, 사전 검수 자원에 근거하므로 증강의 신뢰도를 데이터 자원 자체가 담보한다. 순환 구조를 갖는 RNN·GRU·LSTM 세 알고리즘에서 증강 전후를 비교했다.

효과는 세 순환신경망 모두에서 나타나, 추론 성능이 최소 0.37%에서 최대 1.25% 향상되었다. 새 데이터 수집 없이 이미 가진 데이터에서 라벨링 비용 없이 얻은 이득이며, 모델 크기를 그대로 둔 채 다른 개선 기법과 중첩해 쌓을 수 있다는 점에 실용적 가치가 있다.

왜 중요한가

모델을 키우지 않고 데이터 표현만으로 성능을 끌어올린 사례 — RNN·GRU·LSTM에서 최소 +0.37%, 최대 +1.25% 향상.

기여

표준국어대사전 유의어 기반 단어그룹 확장학습으로 RNN·GRU·LSTM 세 순환신경망에서 최소 0.37%~최대 1.25% 추론 성능 향상을 실증해, 모델을 키우지 않고 데이터 표현만으로 성능을 개선하는 방법을 제시했다.
