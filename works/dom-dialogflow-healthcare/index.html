Dialogflow를 활용한 헬스케어 챗봇 구조 연구

A Study of Healthcare Chatbot Structure using Dialogflow

한국정보통신설비학회 하계학술대회 · 2021.08 · 공동저자(제4저자)
저자 박대승 (제4저자) 외 공저
요약 SummaryGoogle Dialogflow 대화형 플랫폼을 기반으로 헬스케어 챗봇의 대화 구조를 설계한 연구다. 건강 관련 문의를 인텐트·엔티티·컨텍스트로 구조화하고, 사용자와의 대화 흐름을 헬스케어 시나리오에 맞춰 조직하는 방식을 다룬다.

헬스케어 영역의 챗봇은 일반 대화와 달리 증상 호소·정보 요청·정서 표현이 뒤섞여 들어오고, 잘못된 응답의 대가가 크다. 이를 안정적으로 다루려면 대화 구조 자체를 헬스케어 맥락에 맞게 설계해야 한다.

본 연구는 Dialogflow의 인텐트·엔티티·컨텍스트 체계를 활용해 헬스케어 챗봇의 대화 흐름을 구조화했다. 사용자의 건강 관련 발화를 유형별로 분류하고, 필요한 정보를 되묻거나 적절한 응답 경로로 연결하는 대화 설계를 제시한다.

헬스케어 챗봇 구현의 초기 구조 연구로, 이후 정서 인식·다중 모델 라우팅을 갖춘 치료적 의사소통 챗봇과 관련 특허로 발전하는 대화 설계의 밑그림이 되었다. 본인은 제4저자로 참여했다.

왜 중요한가

헬스케어 챗봇 실装의 초기 구조 연구.

기여

Dialogflow의 인텐트·엔티티·컨텍스트 체계로 헬스케어 챗봇의 대화 구조를 설계해, 건강 문의를 유형화·연결하는 대화 흐름의 초기 구조를 제시했다.
