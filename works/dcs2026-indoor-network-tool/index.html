국내학술

실내이동경로 정량적인 생성을 위한 실내 이동 네트워크 도구 개발 연구

Development of an Indoor Movement Network Tool for Quantitative Indoor Route Generation

🏆 우수논문상 (일반)
한국디지털콘텐츠학회 2026 하계종합학술대회 (제주, 오션스위츠 제주호텔) · 발표번호 A7-04 · 2026.07.01–03 · 공동저자(제2저자)
저자 최재민, 박대승, 이지연, 이채석 (KAIST 공과대학 융복합연구센터) · 교신저자 이채석
초록 Abstract본 논문에서는 SHP 기반 실내공간을 정량적으로 분할하고, 격자 중심 연결 방식과 자유 좌표 연결 방식을 이용하여 실내 이동 네트워크를 구축·편집하는 시스템을 제안한다. 제안 시스템은 PyQt5, GeoPandas 및 Shapely를 기반으로 회전 보정 공간분할, 네트워크 생성·분할, 속성 편집 및 SHP 저장 기능을 제공한다. 공공기관 등 13개 실내공간 데이터에 적용하여 동일한 환경에서 공간분할과 네트워크 작성이 가능함을 확인하였다. 제안 시스템은 SHP 기반 실내 네트워크 구축을 지원하고, IndoorGML 구축을 위한 기초 공간자료 작성 도구로 활용할 수 있다.

노드-링크로 표현되는 실내 이동 네트워크는 그간 상당 부분 수작업으로 그려져, 같은 공간이라도 작성자에 따라 결과가 달라지고 정량적으로 재현하기 어려웠다. 본 연구는 SHP 기반 실내공간을 정량적으로 분할하고 이동 네트워크를 자동 생성·편집하는 도구로 이 문제를 다룬다.

제안 시스템은 PyQt5·GeoPandas·Shapely를 기반으로 회전 보정 공간분할, 격자 중심 연결 방식과 자유 좌표 연결 방식의 네트워크 생성·분할, 속성 편집, SHP 저장을 하나의 GUI에서 제공한다. 격자 방식은 규칙적인 실내를 정량적으로 다루고, 자유 좌표 방식은 비정형 공간을 유연하게 잇는다.

공공기관 등 13개 실내공간 데이터에 적용해 동일한 환경에서 공간분할과 네트워크 작성이 가능함을 확인했다. 제안 도구는 SHP 기반 실내 네트워크 구축을 지원하며, IndoorGML 구축을 위한 기초 공간자료를 작성하는 도구로 활용할 수 있다. 본 논문은 한국디지털콘텐츠학회 2026 하계종합학술대회에서 우수논문상(일반)을 수상했다.

구조 · 설계

SHP 기반 실내공간 입력 → 회전 보정 정량 격자 분할 → 격자 중심/자유 좌표 방식의 네트워크 생성·분할 → 속성 편집 → SHP 저장으로 이어지는 PyQt5·GeoPandas·Shapely 기반 GUI 파이프라인.

왜 중요한가

실내 이동 네트워크 구축의 수작업 한계를 SHP 기반 정량 분할과 GUI 자동화로 해소해, IndoorGML 등 실내 공간정보 표준 구축의 기초 자료 작성을 지원한다.

기여

수작업에 의존하던 실내 이동 네트워크 구축을 SHP 기반 정량 격자 분할과 GUI 자동화로 표준화해, 동일 환경에서 재현 가능한 네트워크 작성과 IndoorGML 기초 공간자료 작성을 지원한다.
